AI Chat Playground (Frontend)

Tech stack
- React + Vite + TypeScript
- TailwindCSS + shadcn/ui (local components)
- Framer Motion
- Lucide React Icons
- react-markdown + remark-gfm + rehype-highlight

Getting started
1. cd frontend
2. npm install
3. npm run dev

Notes
- This project is UI-only with a fake API in src/services/mockChatService.ts.
- The codebase uses a feature-based folder structure to make it easy to connect to a real Express + Gemini API later.
